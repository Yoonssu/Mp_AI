# 🦜 FinPilot : 하이브리드 2-Track RAG 기반 금융 자산 컨설팅 에이전트

> **66개의 실제 은행 약관 PDF 데이터를 기반으로 맞춤형 상품을 전수조사하고, 파이썬 연산 엔진을 통해 무결성 만기 이자를 계산하는 대화형 ReAct 금융 비서 서비스입니다.**

---

## 📌 1. 기획 목적 (Background)
* **금융 정보의 비대칭성 해소:** 시중에 존재하는 수많은 은행의 적금 상품들과 복잡한 우대금리 자격 조건으로 인해 발생하는 금융 소비자(특히 사회초년생)의 피로감과 번거로움을 줄이기 위함.
* **해결 방안:** 자연어 질문 하나로 여러 은행의 상품을 비교 분석하고, 구체적인 우대조건 조회부터 환각 없는 정밀 만기 수령액 계산까지 원스톱으로 해결해 주는 금융 에이전트 구현.

---

## 🏗️ 2. 시스템 아키텍처 (Architecture Deep Dive)

프로젝트는 데이터의 정확성과 멀티턴 대화의 안정성을 보장하기 위해 **4개의 독립된 레이어**로 이원화되어 설계되었습니다.

* **State & Routing Layer (`LangGraph`):** `AgentState` 기반의 중앙 집중형 대화 제어 흐름 구축. `MemorySaver` 체크포인터를 내장하여 다중 사용자의 독립적인 Multi-turn 세션 컨텍스트를 동적으로 라우팅 및 보존.
* **Abstraction Layer (`LangChain`):** 정성적 검색 툴과 정량적 연산 툴을 OpenAI 규격의 JSON Schema 형태로 LLM과 유기적으로 바인딩(`bind_tools`).
* **Data Layer (`ChromaDB` & `Upstage Solar`):** 검색 정확도와 속도를 모두 잡기 위한 **2-Track 하이브리드 RAG** 설계
  * **Track A (요약 컬렉션):** LLM이 사전 압축한 고순도 요약본(66개 청크)을 기반으로 1차 전수조사 수행.
  * **Track B (상세 컬렉션):** 원본 문서를 1,000자 단위로 촘촘히 쪼갠 파편 컬렉션. 특정 상품 타겟팅 시 `filename` 메타데이터 필터링을 통해 정밀 검색 격리.
* **Compute Layer (파이썬 연산 모듈):** LLM의 고질적인 '수학적 환각(Math Hallucination)'을 원천 격리하기 위해, 연산 책임을 백엔드 런타임 코드로 완전히 이관하여 금융 단리 수식의 무결성 보장.

---

## ⭐ 3. 핵심 기능 (Key Features)
* **1단계 상품 후보 전수조사:** 사용자 맞춤형 상위 5개 금융 상품 풀(Pool) 고속 추출 및 제언.
* **2단계 우대금리 조건 딥다이브:** 대화 맥락을 추적하여 특정 상품의 실제 상세 조항(급여 실적, 카드 조건 등) 매칭 및 정밀 RAG 수행.
* **무결성 만기 수령액 산출:** 숫자가 100% 보장된 진짜 세전 이자 및 예상 총 수령액 도출.

## 🔥 4. 핵심 트러블슈팅 (Troubleshooting)

### 🚨 연속 질문 시 LLM 멈춤(Deadlock) 및 UI 서식 도돌이표 중복 출력 버그
* **원인:** UI단에서 대화록을 수동 누적하여 전달하는 방식과 LangGraph의 제어권이 충돌하여 API 타임아웃 발생. 또한 초기 진입 노드(`force_first_inspection`)가 연속 질문의 맥락을 파싱하지 못하고 데이터를 오염시켜 컨텍스트가 상실됨.
* **해결:** 백엔드 그래프 내부에 `MemorySaver` 체크포인터와 `thread_id` 세션 스코프를 통합하여 컨텍스트 자동 관리화. 연속 질문이 감지되면 1차 요약 DB 조회를 스마트하게 스킵하고 에이전트 노드로 직행하는 **우회 라우팅 파이프라인**을 구축하여 응답 속도를 **0.5초 대**로 극대화하고 UI 중복 현상 박멸.

### 🚨 LLM의 수학적 환각으로 인한 금융 이자 연산 데이터 붕괴
* **원인:** 프롬프트 통제력 약화로 LLM이 계산기 툴을 건너뛰고 자의적으로 계산을 지어내는 환각 발생. 또한 LLM이 도구 인자에 기호(%, 원)를 섞어 보내 파이썬 코드가 크래시나는 현상 목격.
* **해결:** `system_prompt`에 행동 순서를 강제하는 프로토콜을 주입하여 도구 결과 반환 전까지 답변 생성을 블로킹함. 더불어 계산기 툴 함수 내부에 **정규식 수집기(`re.findall`) 패턴 매칭 알고리즘** 레이어를 전면에 배치하여 완벽한 입력 값 데이터 가공 및 수식 무결성 달성.
